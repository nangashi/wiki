# insightコレクション 過剰主張監査（2026-08-23）

Codex（`codex exec` を3並列・各25ページ）に全75ページの「過剰な主張（overclaiming）」検出のみを依頼し、
主要な指摘をClaude Codeが原文照合で検証した結果。

検証区分:
- **確認済み**: 該当ページを実際に読み、引用と文脈が原文と一致することを確認した
- **要確認**: Codexの指摘のみで、原文照合または一次資料への遡行をしていない

## Codex出力の信頼度について

Codexは75ページ中66ページを指摘し、うち58件を「深刻度 高」と判定した。この検出率は明らかに過検出で、
そのまま採用すると優先順位が失われる。特に「著者の枠組み（コヴィーの4能力、チャルディーニの7原則、
NVCのニーズ定義）を実証済み機構として書いている」型の指摘は、帰属を明示すれば解消する書き方の問題であり、
主張の強さの問題とは分けて扱う必要がある。以下はClaude Code側で三層に切り分けた結果。

## A. 事実として誤っている／根拠が追えない（優先修正）

### A1. `prospect-theory` — 理論内容の誤り（**確認済み**）

> これも核心の「参照点からの変化」で感じるという原理の帰結であり、変化量の感度は参照点からの距離に**反比例**する（限界効用逓減の感情版）

価値関数は参照点から離れるほど傾きが緩やかになる（凹凸性）だけで、「距離に反比例」という関数形ではない。

> 少確率の出来事（宝くじ、保険）は過大評価される — 参照点からの僅かな変化に感度が高い**感度逓減の逆効果**として、ゼロ付近の確率変化が過剰に感じられる

少確率の過大重みづけは価値関数ではなく**確率加重関数**という別の構成要素による。プロスペクト理論の
2要素構造を混同している。

修正案:
- 「参照点から離れるほど、同じ大きさの追加変化が主観に与える影響は小さくなる」
- 「少確率の出来事が過大に重みづけられる傾向は、結果の価値を表す価値関数とは別の『確率加重関数』でモデル化される」

### A2. `motivational-questioning` — 動機づけ面接の定義の誤り（**確認済み**、原典未照合の点は要確認）

> カウンセラー（または問いかける側）の役割は、相手が自分の現状・信念・行動をより明確に見られるよう反射することであり、方向を指定することではない。

動機づけ面接は「クライアント中心かつ**方向性を持つ（directive）**」ことが定義上の特徴で、非指示的
カウンセリングとの差分がまさにそこにある。また「問いかけは防衛を起動させない」も強すぎる（詰問形式の
質問は防衛を強める）。

修正案: 「相手の自律性を尊重しながら、本人が望む変化の方向に沿って両価性を探索し、変化についての発言を
引き出す」／「開かれた問いは一方的な主張より防衛反応を弱めることがあるが、誘導・詰問と受け取られる質問は
逆効果になりうる」

### A3. `environment-design-behavior` — 自我消耗モデルを無留保で採用（**確認済み**）

> 意志力は有限なリソースであり、誘惑に「抵抗する」ことを前提とした戦略は長続きしない。

意志力を消耗する単一資源とみなすモデルは大規模追試で再現性が争われている。このページの核心（環境設計の
有効性）はこのモデルを前提にしなくても成立するため、依存を外す方が主張が強くなる。ページに適用限界
セクションもない。

修正案: 「誘惑への抵抗を繰り返す戦略は、疲労・注意・動機づけ・状況によって維持しにくくなるため、
環境設計を併用する方が安定しやすい」

### A4. `inu-no-michi` — 出所不明の数値＋数学的に不正確な説明（**確認済み**）

> **確率が変わらない**: 全問題の2〜3%しかない「本質的なイシュー」に偶然当たる確率は、アウトプット量を増やしても変化しない

「全問題」の母集団も「本質的なイシュー」の判定基準も定義されておらず、2〜3%の出所が追えない（sourcesは
書籍1件＋個人ブログ2件）。加えて、試行数を増やせば「少なくとも1回当たる」確率は上がるため、
「量を増やしても確率は変わらない」という説明自体が正確でない。概要の「確率が構造的にほぼゼロ」も同様。

修正案: 「価値の低い問いへのアウトプットを増やしても、問いの選び方を改善しない限り、本質的な問いへ
到達しやすくはならない」（数値を外し、確率の主張を『問いの選択は量に依存しない』に限定する）

### A5. `org-productivity-misdiagnosis` — 出所のない数値に「（認知科学）」を付している（**確認済み**）

> 5分の依頼が実際には50分の中断コストを発生させる（認知科学）

sourcesはサイボウズ式の記事1件のみで、この50分に対応する研究がない。「（認知科学）」という括弧書きが
実在しない学術的裏づけを装っている点が特に問題（同種の俗説「復帰に23分15秒」に隣接する）。

修正案: 「短い依頼でも、作業の切替と元の課題への復帰によって、依頼時間を大きく超える中断コストが生じる
ことがある」（`interruption-recovery-cost` へのリンクで根拠を担保する）

### A6. `shin-dokkai` — 相関の解釈と基準値（**確認済み**）

> RST（リーディングスキルテスト）と学力の相関は0.4〜0.7（通常「高い」とされる0.2を大幅に上回る）

「0.2を通常高いとする」基準は一般的でない。さらに同じ文で「学力全体の天井がシン読解力によって規定される」
と因果を述べており、相関からの飛躍になっている（語彙・一般知能・既有知識という共通要因で説明可能）。

修正案: 「RST得点と学力指標には中程度から強い相関が報告されている。ただしこの相関だけから、RSTが測る能力が
学力の上限を因果的に決めるとはいえない」

### A7. `community-of-knowledge` — 脳容量のバイト換算（**確認済み**、原典は要確認）

> 個人の脳が保持できる情報量には根本的な限界がある（推定0.5〜1GB程度）

記憶をバイト単位に換算する標準的な尺度は存在せず、この種の数値は単一の古い推定に由来する。核心（認知的分業）
に数値は不要。

修正案: 「個人が保持し、必要な場面で正確に利用できる知識には限界がある」（数値を落とす。残すなら
「〜の推定がある」と誰の推定かを明示する）

### A8. `productivity-layer-model` — 出所と単位が不明な数値の対比（**要確認**）

> 個人開発者の体感: AI導入で「速くなった」(約+20%) ／ 実態データ: 組織のデリバリー安定性は負の相関(約−19%)

sourcesがSpeaker Deck1件で、母集団・指標・測定期間が追えない。「体感」と「実態データ」が同一対象・同一
尺度かも不明なまま、この2数値の対比から6層モデルの因果（L3の調整コストが原因）を導いている。

修正案: 数値は「紹介元資料では〜という事例が示されている」に格下げし、因果は「個人作業の改善が調整工程で
吸収されている可能性を示すが、測定差や品質変化など他の説明も検討が必要」と留保する。

### A9. `growth-vs-fixed-mindset` — ページ内で主張が矛盾している（**確認済み**）

概要「信念が…長期的成果を**決定する**」／「『まだできない』と言い換える**だけで**…転換が起きる」に対し、
本文後半は「介入の効果規模は小さく（大規模メタ分析）」「口で言うだけでは介入効果を持たない」と書いている。
後半が正しいので、概要と「まだ」の節を後半に合わせる。

修正案: 概要を「〜と関連し、挑戦への行動や失敗への反応を左右する」に、「まだ」の節を「捉え直しの手がかりに
なりうるが、言い換えだけで信念や行動が変わるとは限らない」に。

### A10. `theory-of-constraints` — 指標の誤分類（**要確認**）

> デプロイ頻度・リードタイム・変更失敗率という**スループット系指標**が…提唱された理由はここにある

変更失敗率はスループットではなく安定性・品質の指標。DORA4指標はフロー系2つと安定性系2つの組で、TOCから
直接導出されたわけでもない。

### A11. `unlearn` — 実験結果の言い過ぎ（**要確認**）

> 既知の解法を見つけた後は盤上により良い手があってもそこに視線すら向かなくなる——「見ようとしない」のではなく、文字通り「見えなくなる」

視線が向きにくくなったこと（注意配分の偏り）を「知覚できない」という別の主張に置き換えている。
「文字通り」を外し、「より良い手に関連する箇所への注意と探索が弱まる」とする。

### A12. `echo-chamber` — バックファイア効果の一般化（**要確認**）

> だから「事実を見せれば分かるはず」という介入は効かず、しばしば逆効果になる。

訂正が信念を強めるバックファイア効果は再現性・一般性が争われており、多くの訂正研究では信念は部分的に修正
される。「効かないことがあり、提示方法によっては反発を招きうる」程度に留保する。

## B. 構造的パターン: 唯一性の主張（横断的に頻出）

書籍由来の規範的主張が「〜のみ」「〜でしか」「〜だけが」という排他的因果として書かれている。個別には
深刻でないが、wiki全体で最も多い過剰主張の型。該当例（いずれも**確認済み**の引用）:

| ページ | 表現 |
|---|---|
| `knowledge-worker-autonomy` | 生産性を高められるのは「知識労働者本人のみ」 |
| `feedback-analysis` | 強みの把握には期待と結果の照合が「唯一の方法」 |
| `exit-criteria-first` | 事前に定義し「なければ回避できない」 |
| `knowledge-externalization` | 外部化された知識「だけが」俯瞰と横断を可能にする |
| `quadrant-ii-principle` | ブロッキングに「よってのみ」実行可能 |
| `pre-analysis-output-design` | 期待する証拠の形を先に定義することで「しか」確定できない |
| `theory-of-constraints` / `local-optimization-trap` | 非制約で節約した1時間は「何の価値も生まない」 |
| `habit-loop` | 「すべての」習慣は4段階サイクルで動作する |
| `parallel-path-trap` | 10%の投資では真の習熟は「不可能」 |
| `unlearn` | アンラーン「でしか」解除できない |

対処方針: 排他表現を「主要因である」「〜しやすくなる」に落とすと同時に、その概念が何と対比されて有効なのか
（どの条件で成り立たないのか）を1行足す。単にヘッジを足すだけだと主張が弱くなるだけで価値が下がるため、
**境界条件を書くことで主張を強くする**方向で直す。

## C. 採用しなかったCodexの指摘

- **著者の枠組みを「実証されていない」と指摘する型**（コヴィーの4能力＝`stimulus-response-freedom`、
  チャルディーニの7原則＝`cialdini-persuasion-triggers`、NVCのニーズ定義＝`needs-vs-strategies`）。
  これは主張の強さではなく帰属の問題。「Xはこう整理している」と出所を明示すれば足り、
  Codexの修正案どおりに全面書き換えると概念の核心が薄まる。
- **`fact-interpretation-action` の表セル「誰が見ても同じ」**。推論のはしごの段階説明であり、
  Codexの修正案（測定条件を書き込む）は表の対比構造を壊す。
- **`availability-heuristic` の「自動的に置き換える」**。カーネマンの属性置換の記述としては原典に忠実で、
  過剰とは言いにくい。

## 全体所見

指摘ゼロだった7ページ（`anchoring-effect` / `nonviolent-communication` / `attention-residue` /
`maturity-continuum` / `planning-fallacy` / `survivorship-bias` / `interruption-recovery-cost`）に共通するのは、
**枠組みの認識論的地位を明記しているか、境界条件を本文に組み込んでいる**こと。手本になるのは
`maturity-continuum.md:36`:

> コヴィーのモデル自体は規範的な自己啓発フレームワークであり、実証理論ではない。ただし独立に対応する研究が複数ある。

および `attention-residue.md:34`（後続研究が示す変動条件を本文に組み込んでいる）。

現状、適用限界セクションを持つのは75ページ中15ページのみ。ただし適用限界セクションの有無と指摘数は
強くは相関しておらず（無指摘7ページのうち5ページは適用限界セクションを持たない）、
**セクションを機械的に増やすのではなく、上記の「出所の格付けを1行書く」型の記述を書籍由来ページに入れる方が効く**。
