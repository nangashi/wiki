# 説得を左右する手掛かりの文書設計

## 読者・目的

- slug: `cialdini-persuasion-triggers`。タイトル「説得を左右する手掛かり」。
- 読者: 勧誘・依頼・助言を受け、承諾や採用へ傾いた人。
- 目的: 手掛かりと採用根拠を分け、追加確認と保留の要否を選べるようにする。
- 中核: 発信者・提示状況の手掛かりによる受容・応諾と採用理由を区別。手掛かりも有用だが、確認対象との対応が必要。
- 想定分量: 本文約5,000字。7原則、権威の二判断、好意と返報の混同、点検案の接続に必要。研究詳細は判断を変える部分に限定。

## 読後の到達点

- D1: 7原則を手掛かりの候補として使い、要求の妥当性や自分の応諾原因を断定しない。
- D2: 権威らしい人物の情報採用と要求への応諾を分け、それぞれに必要な確認を選べる。
- D3: 好意なら特に好感のない相手、返報なら便宜を受けていない場合、一体感なら所属を共有しない相手を想定し、同じ内容を採用・承諾するか確かめる。返報では便宜と要求の釣り合いも確認する。好意・返報の判別不能時は両方、ほかも複数候補なら各確認を当てはめる。どれでもない・不明の場合も共通の内容点検（根拠・権限・負担・代替）へ進み、採否・保留を選べる。
- 適用テスト: 共同制作チームの進行役が「この分担なら納期を守れる」と説明し、全員の同意欄への署名を求めた。あなたは以前その人に作業を助けてもらい、今回も同意へ傾いている。→ 好意・返報を判別できなければ、好感のない相手でも、以前の助力がなくても署名するか、助力と要求が釣り合うかを確認。同じチームという所属も候補なら、それを外した想定を加える。回答によらず、納期予測は作業量・担当者の見積もり、署名は決定権限・負担・代替分担を確認。不足が残れば署名を保留。

## 内容と順序

| 順序・役割 | 伝える内容・使用材料 | 到達点 |
|---|---|---|
| 1 判断が動く入口 | 承諾と採用根拠の区別。S6の正確さ・関係維持・肯定的自己像と外部要因の相互作用。手掛かりを不合理と決めつけない | D1 |
| 2 7原則の見取り図 | 下表を原因診断でなく提示状況の候補整理に使う。好意と一体感を区別 | D1 |
| 3 権威を前にした二つの判断 | 情報採用／応諾と確認事項を対応づける。S9とS8は別の判断が動いた観察 | D2 |
| 4 好意だけでは説明できない応諾 | S10の実験と限界。D3の好意・返報・一体感別確認、判別不能時の併用、共通点検へ接続。点検効果をS10から導かない | D1、D3 |
| 5 採否を再検討する | 期間限定の講座申込みを架空例に、期限の事実・学習目的との適合・総費用・代替講座を分ける。点検案とS7の境界を接続 | D2、D3 |
| 6 関連 | 残す4原則の仕組みや区別を補うリンク | D1、D3 |

7原則はS5の掲載順。反応を決めつけない。

| 原則 | 手掛かりの候補 |
|---|---|
| 返報性 | 先に受けた便宜・親切 |
| 希少性 | 数量・機会・期間の制限 |
| 権威 | 信頼できる専門家という評価。肩書き・制服だけで専門性を認定しない |
| 一貫性 | 過去の表明・約束・行動 |
| 好意 | 相手への好感・親しみ |
| 社会的証明 | 他者の選択・行動 |
| 一体感 | 共有するアイデンティティ、「私たち」という所属認識。単なる好感・類似性と区別 |

権威の比較軸: 判断対象／確認事項。

- 情報の採用: 主張の正しさ。専門領域の一致・裏付け・利害を確認。
- 要求への応諾: 行動の引受け。要求する役割・権限・要求の範囲を確認。
- 肩書き・制服は十分な根拠にならず、役割・専門性と個別の要求・主張との対応を確認。利害だけで虚偽とせず、適切な専門家への信頼を否定しない。

点検案は4段階。

1. **候補を言語化**: 手掛かりを挙げる。複数候補・不明でも進む。
2. **判断対象を分ける**: 手掛かりと内容、情報採用と応諾を分離。D3の候補別確認を適用し、判別不能なら併用。該当なし・不明でも次へ。
3. **根拠を照合**: 想定への回答だけで採否を決めず、全ケースで根拠・権限・負担・代替を確認。正当な期限や専門性も確認後の材料にする。
4. **採否または保留**: 材料がそろえば採用・承諾。不足し即答不要なら保留、別の情報源・条件書を確認。

|---|---|---|

| 情報源で受け入れが変わる | S9。同内容を高・低信頼源に帰属。直後に伝え手の方向へ動いた意見の純変化率の平均23.0%対6.6%（各条件N=122事例、p<.01、Table 3、p.643）。事前・直後・4週後の全回出席者61人（pp.637, 640）が複数論題を読む分析で、人数の割合ではない。事実情報の習得量に有意差なし | 観察。理解の測定全般ではなく、事実情報の習得と意見変化の区別。命令への服従ではない |
| 服装で応諾が変わる | S8。路上で私服・牛乳配達員・警備員の服装を比較し、警備員への応諾が多い。依頼例は紙袋拾い | 要旨の観察。専門性の証拠としない。応諾率・実験者の性別・パーキングメーターの設定は書かない |

| 自己診断だけで点検を終えない | D3の候補別確認と共通点検 | 効果未実証の記事側の提案。S10は自己診断の誤り・点検効果を測っておらず、確認案を同実験から導かない |
| 警告だけで抵抗は保証されない | S7。警告された参加者は高関与かつ警告とメッセージ間の認知的妨害なしで抵抗。低関与では警告・妨害の水準によらず説得された | 条件付きの観察。7原則への気づきや時間を置く対策自体の検証ではない |

- S8の機序・監視操作・質問紙は省略。機序を扱うには著者の正統性解釈と、大学生が警備員の力・正統性を高く認知しなかった質問紙結果の併記が必要なため。
- S9の4週後、S10の好意との相関係数は省略。持続効果・好意から応諾への因果を論じない。
- 手掛かりがあれば不当、気づけば影響を除去できる、保留すれば判断が改善する、とは主張しない。

## 採用・省略

- **比較を採用**: 情報採用／応諾は確認対象、好意／返報／一体感は関係の種類・手掛かりを外した想定での採否を比較。返報は便宜と要求の釣り合いも追加。確認内容が変わる違いを優先。
- **現実への適用を採用**: 講座例で焦りによる申込みを期限・受講理由の個別確認へ変える。実験と同じ効果量は予測しない。
- **行動指針を修正して採用**: 比較直後に候補別確認、判別不能なら併用、該当なし・不明でも共通点検へ。原因特定を前提とせず、効果未実証の提案とする。
- **省略**: Burger et al.（2001）、Baron（1971）、好意の要因一覧、ミルグラム実験、動物行動の比喩、原則追加史。判断を変えない網羅を避ける。
- **統合の扱い**: 好意・権威の独立節で区別を引き受け、削除対象2記事へリンクしない。独自の機序を持つ4記事は関連欄へ。
- **引用の制限**: UnityはS11の発言の要約。未確認の『Pre-Suasion』本文を引用しない。
