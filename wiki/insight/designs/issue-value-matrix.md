# イシュー度×解の質マトリクスの文書設計

## 読者・目的

分析や資料の精度を高め続けているが、その答えが何の判断に使われるか曖昧な担当者が対象。答える必要性と答えの確かさを分け、問いの見直しと解の改善のどちらを優先するか選ぶ。

## 読後の到達点

- D1: イシュー度を今答える必要性、解の質を問いにどこまで答えられているかとして区別し、明確さと裏付けは記事側の点検基準だと説明できる。
- D2: 問いの必要性が低い場合は問いを見直し、必要性が高く答えが弱い場合は根拠を補うという異なる判断を導ける。
- D3: 二軸を実務の判断モデルとして使い、価値を測る普遍的な掛け算や、探索的仕事の無価値判定にしない。

## 内容と順序

1. 二軸を概要で定義し、両方を点検するモデルと位置づける。解の質を点検するため、記事では答えの明確さと根拠の裏付けを見る、と原著の二軸と記事側の具体化を分ける（D1）。
2. 同じ分析業務を例に、答えで打ち手が変わるかと、打ち手を選べるだけの根拠があるかを別に問う（D1、D2）。
3. 二軸の組合せに応じて、問いの再設定、必要な根拠の追加、判断へ進むという行動を選ぶ。「犬の道」は答える必要性を確かめず解だけを磨く進め方として説明（D2）。
4. 期限・利用者・判断が変われば必要性も変わり、探索や基礎知識獲得の目的なら即時の打ち手だけを価値基準にしない（D3）。

## 主張と根拠・境界

- S5（一次・追加）: 安宅和人の対談と書籍p26の抜粋、https://www.1101.com/ataka_kazuto/2012-01-12.html 。イシュー度と解の質を分け、現在答える必要性を重視する著者の主張を確認。原著の強い「価値はゼロ」という表現は実務上の強調で、検証済み数理法則としない。
- S6（一次・追加）: 出版社による著書案内、https://eijipress.co.jp/products/2356 。今答えるべきで答える手段のある問題を選ぶこと、解の質だけでなくイシュー度を高めること、犬の道の説明を確認。
- 二軸からの判断手順と、解の質を明確さ・裏付けで点検する基準は著者の実務原則を具体化した記事側の提案。「裏付け」を原著の定義文へ帰属しない。書評に旧版p26の「どこまで明確に答えを出せているか」という引用は確認できるが、一次の公開抜粋だけではその定義文全文を確認できていないため逐語引用はしない。改善の因果効果や生産性倍率は主張しない。受け手の選択に関わる研究・分析が主な射程で、すべての学習や創作を即時の問題解決へ還元しない。
- 既存S1〜S4は本文確認済みの一次資料S5・S6へ置換し、IDを再利用しない。

## 採用・省略

- 比較は採用する。必要性と確かさを混同しない二軸比較が記事の中心である。
- 現実への適用は採用する。精密な資料でも判断が変わらないなら、さらに精密化する前に利用目的と問いを見直す。
- 行動指針は採用する。答えの違いで何が変わるか、何を確かめれば選べるかを順に問い、必要な根拠に絞る。
- 数値的な積、問いの一方的支配、常識への反命題をすべての良い問いの必要条件にする説明は省く。一次情報だけが常に不可欠という断定も省く。
