# Insight設計評価: language-context-dependence
- reusability_gate: 合格

## 再利用性ゲート
- R1: 表現場面と文章理解の不一致から、別の読解困難も診断できる。
- R2: 目的・共有文脈・言語選択の関係が、個別例を除いても残る。
- R3: 異領域への一般化を採用理由としておらず、適用対象外である。
- R4: 英語研究の範囲と日本語への非転用、二分法を避ける条件が明確である。

## 観点別評価
| 観点 | 状態 | 根拠 |
|---|---|---|
| 読者・目的 | 十分 | 会話力から読解力を推定する読者の誤判断と用途が具体的である。 |
| 読後の到達点 | 十分 | 定義・比較・学び方の判断が、本文で確認可能な形になっている。 |
| 内容と順序 | 十分 | 定義、比較、研究知見、点検手順の順に理解と判断を組み立てる。 |
| 主張と根拠・境界 | 十分 | 原論文が示す語彙・文法・社会経験の範囲と記事側の提案を分ける。 |
| 採用・省略 | 十分 | 比較・適用・行動を残し、根拠のない因果則と文化論を除いている。 |
