# Insight記事評価: avoidance-generated-reasons
- reusability_gate: 合格

## 再利用性ゲート
- R1: 合格。「延期を望む目標があると、延期を支える理由が選ばれ構成されうる」という関係（15〜21行目）から、ソースにない場面でも判断を変えられる。例えば、理由が増えたり入れ替わったりしたときに、判断材料がそろったとも言い訳だとも決めず、「どの判断を変える理由か」で点検できる（21、32行目）。調査の前に問いと見直し時点を書いておく（40行目）、重要度・見込み・費用の三点で継続・絞り込み・保留を選ぶ（57〜69行目）といった行動にもつながる。
- R2: 合格。業務ツールやA/Bといった固有の例を除いても、「方向目標→理由の探索と評価の偏り→延期の正当化」と「待つことの情報利得と機会損失」の二つの関係が残る。記事の外の延期場面にも同じ役割の要素を当てられる。
- R3: 対象外。異なる領域への一般化を採用理由にしておらず、S3の経験も「一般化した実証結果とは扱わない」としている（104行目）。
- R4: 満たす。「適用境界」節（86〜92行目）で、期限は機械的な選択規則ではないこと、言葉にできないことは回避の証拠にならないこと、費用の判断を動機の診断に使わないこと、並行が探索や併用なら続けてよいこと、他者を非難する用途に使わないことを示している。点検手順の効果が確かめられていないことも36行目で明示している。

## 記事単独読解
- 概念と関係: この記事は、「情報が足りない」「合意がない」といった延期の理由が、判断を実際に妨げる制約と、延期の正当化という二つの役割を同時に持ちうると説明する（S1 Kundaの動機づけ推論とS2 Andersonの決定回避を延期の場面につないだ記事側の仮説）。そこから、理由は「本物か言い訳か」ではなく「判断をどう変えるか」で見分けるべきだとし、並行比較の例では目的・得られた情報の役割・見直し時点・次の判断の四つの軸で、判断に必要な探索、役割のある併用、判断につながらない比較継続を区別している。
- 現実の見方: 延期の理由が増えたり入れ替わったりしても、判断材料がそろったことにも言い訳の証拠にもならず、点検を始めるきっかけにすぎないと見るようになる。行動としては、調査の前に「答える問い・その答えで変える判断・見直し時点」を書いておく。問いを示せないときは先に問いと基準を立て直す。調査の後には、変わりうる判断の重要度、答えが得られる見込み、延期の費用の三点を比べ、答えを得る価値が費用に見合えば継続、手持ちの情報で進められれば絞り込み、進められなければ再開条件を書いて保留する。
- 確かさ: 区別できる。方向目標が理由の探索を偏らせること（S1）、決定回避には合理的な待機と機会損失の両方があることと bolstering の概念（S2 p.139-140）、並行比較への批判と留保（S3）は出典に帰属されている。一方、延期に伴って理由が生成されるという結びつき、三点比較の手順、三つの判断分岐、表の分類は「記事側の仮説・提案」であり効果は検証されていないと、本文19・36行目と外部ソース欄で繰り返し明示されている。
- 理解が止まった箇所: 立て直しで問いを「具体化できなかった」場合も絞り込みか保留へ進むとされている（51行目）が、絞り込みの条件は「必須条件が満たされているかを確かめる」ことを前提にしている（68行目）。基準を示せない状態でそれをどう判定するのかが分からない。また、手順が回避動機の推定を一貫して禁じているため、中心にある仮説（理由が延期を支える）が一般的な費用対効果の点検と比べて何を変えるのかは、「理由の数を判断材料と数えない」という一点以外には読み取りにくかった。

## 対応項目
### P1: 調査前に記すことと仮説の接続を文中で示す
- 種別: 任意改善
- 観点: 核心と推論力
- 対象箇所: 「先に記しておけば、調査の後で出てきた理由を当初の条件と照らし合わせられる。」
- 問題: 仮説（延期を望むと、延期を支える理由が後から選ばれ構成されうる）が手順に直接働くのはこの箇所だが、なぜ後から出た理由を当初の条件と照合する必要があるのかが書かれていない。そのため、手順が仮説なしでも成り立つ一般的な費用対効果の点検に見え、仮説によって何が変わるのかを読み取りにくい。また21行目の「また待つことには機会損失があるため…」は「この仮説から」に続く形で書かれているが、実際の根拠はS2の延期費用であり、仮説から導いたものではない。
- 改善後に満たす条件: 40行目で、調査の後に出た理由は延期を支える方向へ選ばれうるため、事前に書いた条件と照合する、という根拠が一文で読み取れる。21行目の二つ目の主張の根拠が、仮説ではなく延期の費用だと読み分けられる。
- 対応方法: 40行目に「理由は調査の後で延期を支える方向へ選ばれうるため」という根拠を短く足し、21行目の「また」以下は延期の費用に基づくことが分かる言い方に変える。

### P2: 具体化できなかった場合の分岐に判定の手がかりを置く
- 種別: 任意改善
- 観点: 論理と構造
- 対象箇所: 「具体化できなかった：立て直しを延長せず、現時点の情報で候補や調べる範囲を絞るか、何を待つかと再開の条件を記して保留する。」
- 問題: 基準が定まらない状態で絞り込みと保留のどちらを選ぶかは、68〜69行目の「手持ちの情報で判断を進められるか」で決まるが、51行目の分岐点にはこの手がかりがない。そのため、絞り込みには必須条件の判定が必要だと読んで止まりやすい（第一段階の読解でも止まった）。
- 改善後に満たす条件: 51行目だけを読んでも、候補を一つに選ばずに範囲だけを縮めることができること、選択は手持ちの情報で判断を進められるかで決まることが分かる。
- 対応方法: 51行目に「手持ちの情報で範囲を縮めて進められるなら絞り込み、進められなければ保留」という判定の手がかりを一句足す。

### P3: 動機を診断しないという留保の繰り返しを減らす
- 種別: 任意改善
- 観点: 日本語の自然さ
- 対象箇所: 「回避とは断定しない」「回避動機を推定できない」
- 問題: 同じ趣旨の留保が19、32、36、80、84、89〜92行目で段落末ごとに再提示されている。読み進めるうちに新しい情報が減り、各節の固有の主張が埋もれやすい。
- 改善後に満たす条件: 判断を変える箇所（32行目の点検の契機、表の三つ目の列）と「適用境界」節には留保が残り、それ以外で同じ結論を繰り返す段落末の文が減っている。
- 対応方法: 84行目の末文や89行目など、適用境界と重なる再提示を削るか短くする。

### P4: 合理的な待機の根拠ページを補う
- 種別: 任意改善
- 観点: 事実基盤
- 対象箇所: 「待てば情報が得られる場面では延期が合理的でありうる一方、延期すれば機会を失う費用も生じる[S2]」
- 問題: 外部ソース欄はp.139を比較の軸の根拠に挙げている。しかしp.139で確かめられるのは延期が機会損失に変わることと理由の混在までで、さらに考えることで得られる利得と延期の損失を比べるという記述はp.148の「costs for delay」の段落にある。読者が根拠をたどるときに、本来のページを見落としうる。
- 改善後に満たす条件: S2の支える範囲に、延期による利得と損失の比較はp.148で扱われていることが記されている。
- 対応方法: 外部ソース欄のS2の説明に「p.148（costs for delay）」を追記する。
