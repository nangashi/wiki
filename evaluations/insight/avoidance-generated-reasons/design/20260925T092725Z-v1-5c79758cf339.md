# Insight設計評価: avoidance-generated-reasons
- reusability_gate: 合格

## 再利用性ゲート
- R1: 合格。このモデルを使うと、元の資料にない判断延期のケースでも診断の仕方が変わる。「まだ情報が足りない」と言われたら、理由を信じるか疑うかで決めない。何が分かれば判断が変わるか、何が解消され何が残ったかを照合する（設計「読者・目的」、D2・D3）。並行比較という新しいケースにも同じ点検を当てはめて、継続・絞り込み・保留を選べる（D4、第5節）。
- R2: 合格。固有の事例を除いても構造が残る。構造は「延期を望む方向目標 → 延期を支持する理由の選択・構成 → その理由がさらに延期を支える」という連鎖である。これに加えて、理由が実在の制約と正当化を兼ねうることも構造に含まれる（「記事側の統合仮説」の段落）。業務の方法A・Bの比較にも、情報不足と合意不足が併存する例にも、同じ要素の対応を付けられる。
- R3: 該当しない。設計は「領域横断の心理法則として効果を一般化しない」と明記している。並行比較の適用例も同じ判断延期の領域内の適用であり、異なる領域への一般化を採用理由にしていない。
- R4: 条件と限界がそろっている。「外せない境界」に次の条件がある。理由の入替えや要求水準の上昇は点検の契機にとどめること、言語化できないことだけで回避と決めないこと、期限は見直し時点であること、配分比率や長期化だけを指標にしないこと、手順は実証済みの介入ではないこと。競合する説明（合理的な待機、複数の制約、基準の曖昧さ）も併記されている。

## 観点別評価
| 観点 | 状態 | 根拠 |
|---|---|---|
| 読者・目的 | 十分 | 読者の状況は「調査・調整・並行比較を続けても決断に近づかない」と具体的に書かれている。読む前と読んだ後の対応の変化も示されている。前は「調査を追加する／回避だと判断する」、後は「何が分かれば判断が変わるかを確認し、継続・絞り込み・保留を選ぶ」である。動機を確定することを目的外にしている点も、他者を非難する用途を防いでいる。吸収範囲を「判断を延期する並行比較」だけに絞るという統括の決定も妥当である。吸収元の資源配分論・習熟論は根拠が弱く、この記事の中心である理由と延期の関係から外れる。`wiki/insight/pages` 内には parallel-path-trap への被リンクがないため、削除してもリンク切れは起きない。 |
| 読後の到達点 | 十分 | D1〜D5 は次の要素にそれぞれ対応している。統合仮説であることの理解、制約と正当化の併存、条件の具体化と照合、並行比較で使う共通の比較軸、理由の変化を動機の診断に使わないこと。不足も過剰もない。どの到達点も本文の節表から確認できる。 |
| 内容と順序 | 要対応 | 節の順序（関係の説明 → 理由だけでは決められないこと → 判断への利用 → 適用例 → 境界）は、前提から応用へ正しく積み上がっている。ただし第4節の判断分岐は継続・絞り込み・保留の3つに限られている。このため、読者が最も迷う「判断を変える問いを示せないが、条件もそろっていない」状態をどの分岐で扱うかが書かれていない。適用例の表で回避を疑われやすい列は「目的と制約を整理し直す」を次の判断にしており、分岐体系の外にある行動になっている（P1）。 |
| 主張と根拠・境界 | 十分 | 各資料の支持範囲を確認した。S1（Kunda 1990、Psychological Bulletin 108:480-498）の要旨には、望む結論へ向かう推論が "seemingly reasonable justifications" を構成できる範囲に制約されるとあり、設計の記述と一致する。S2（Anderson 2003、Psychological Bulletin 129(1):139-167、DOI 10.1037/0033-2909.129.1.139）は本文PDFの p.139 で "a mixture of a few good, rational reasons for avoidance and ... emotions"、p.140 で "multiple causation" を述べており、合理的な待機と複数要因の併存を残すという設計の使い方を支える。S3（nwiizo「おい、方法を選べ」2026-02-17）の「選ぶとは、捨てることだ」節には、90:10 を「保険」とする批判、「選択と先延ばしの区別がつかなくなります」という警句、「80:20くらいのリソース配分で複数の選択肢を探索すべき場面もあります」という留保があり、設計が警句と留保だけを使うという範囲は資料と一致する。同節には「10%では何も得られません」という断定もあるが、設計はこれを採用していない。資料の知見、記事側の統合仮説、記事側の提案の3層が区別されており、調査が必要な未確認主張はない。 |
| 採用・省略 | 十分 | 比較・現実への適用・行動指針の3つについて、どれも採用とし、それぞれ理由を記している。数値の一般則、公言を唯一の脱出法とする説明、既存設計で退けた主張を明示的に省略しており、根拠の弱い内容が再び入り込むのを防いでいる。関連リンクの採否（hypothesis-as-stance と learning-depth-and-breadth-roles を省略）にも理由がある。 |

## 対応項目
### P1: 判断を変える問いを示せない状態の扱いを分岐体系に組み込む
- 種別: 修正必須
- 観点: 内容と順序
- 対象箇所: 「第4節の判断分岐は、次の条件で具体化する。」の3分岐と、表の「判断へのつながりが不明な比較継続」列にある「目的と制約を整理し直す。回避とは断定しない」
- 問題: 継続は「未回答の問いと、その回答が変えうる判断が示せる場合」の分岐である。絞り込みは「判断に必要な条件が満たされ」た場合、保留は「重要な条件が未確定で、現在の追加調査では解消できない場合」の分岐である。しかし「確かめる問いも判断基準も示せず、条件がそろったかどうかも判定できない」状態は、この3つのどれにも当てはまらない。この状態は、読者が決断に近づかないと感じる典型的な場面である。現行記事は「要求水準だけが引き上げられている場合 → 見直す契機」という分岐でここを扱っていたが、設計ではその受け皿が「外せない境界」の注意書き（「具体的条件をすぐ言語化できないことだけで回避としない」）と、適用例の表の1セルに分散している。その結果、D3「継続・絞り込み・保留を選べる」を満たすための手順が、最も必要な場面で途切れる。執筆担当も、第4節と第5節の表の対応を自分で考え直すことになる。
- 改善後に満たす条件: 第4節で、問いや基準を示せない状態に対する行動（例：不確実性・関係者間の相違・判断基準を整理して問いを立て直し、その後で3分岐へ進む）を、3分岐の前段階または明示的な分岐として定義する。そのうえで、第5節の表の「判断へのつながりが不明な比較継続」列の「次の判断」をこの定義と対応させる。回避と断定しないという境界と、要求水準の上昇は点検の契機にとどめるという境界は維持する。
- 対応方法: 「第4節の判断分岐」の直前か冒頭に「問いの再設定」の条件と行動を1項目加える。第5節の表の該当セルは、その項目を参照する形に揃える。内容と順序の表の第4節の行にも、この要素を一言加える。

### P2: S2の「bolstering」を統合仮説の先行する説明として検討する
- 種別: 任意改善
- 観点: 主張と根拠・境界
- 対象箇所: 「S1・S2がこの因果連鎖全体を確立したとは書かない。」
- 問題: S2本文 p.140 は、Janis & Mann の conflict model に含まれる防衛的回避（defensive avoidance）を紹介し、その一形態として "bolstering, in which the decision maker seeks reasons, in a biased manner, to support an inferior course of action" を挙げている。これは、回避の文脈で理由を偏って探すという記事側の統合仮説に最も近い先行する定式化である。設計はこの点に触れておらず、統合仮説がS1・S2の組み合わせだけから導かれたように読める。
- 改善後に満たす条件: 使う場合は、S2が紹介する先行モデル内の概念として位置づける。延期に伴って理由が再生成されることを実証した資料としては扱わない。統合仮説という位置づけも維持する。
- 対応方法: S2の支持範囲の記述に1文加えるかどうかを判断する。加えない場合もそのままでよい。

### P3: 並行比較での「順番を変える」選択肢を採否に記す
- 種別: 任意改善
- 観点: 採用・省略
- 対象箇所: 「parallel-path-trapの独立した罠の定義、資源配分論、習熟論、集中の推奨は移植しない。」
- 問題: 吸収元の旧設計の「範囲縮小や順番の変更を比較する」は、資源配分の一般則ではなく、判断の分岐の一つとして扱える。たとえば必須条件の確認をAから先に行うといった形である。この選択肢を絞り込みに含めるのか、捨てるのかが書かれていないため、執筆担当が判断することになる。
- 改善後に満たす条件: 順番の変更（直列化）を絞り込みの一形態として扱うか省略するかを、理由とともに採用・省略の節に記す。
- 対応方法: 「吸収範囲を限定する」の項目に1文加える。

## 良い点
- 読者・目的の段落で読む前と読んだ後の対応を具体的な行動で対比しており、動機を確定することを目的外として明記している。
- 適用例の表は3つの列に共通の4つの比較軸を使っている。探索や併用を否定する記事にも、配分比率から回避を推定する記事にもならない。
- 資料の知見（S1・S2）、記事側の統合仮説、記事側の適用・提案、著者の経験（S3）を分けて書いている。それぞれについて、何を支えないかも明記している。
- 根拠の弱い吸収元の主張（「10%では習熟できない」、90:10 を罠の指標とする説明、100:0 の推奨、公言を唯一の脱出法とする説明）と、既存設計で退けた主張を名指しで省略している。改稿で逆戻りするのを防げる。
- 期限を「見直し時点」と定義し、情報が最も多い案を自動的に選ばせない境界を保持している。
