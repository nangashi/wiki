# Insight設計評価: exit-criteria-first
- reusability_gate: 合格

## 再利用性ゲート
- R1: 回収不能な既投資が継続判断を偏らせうるという関係から、未知の案件でも過去の支出と現在以降の費用・便益を分けて再評価する判断を導ける。
- R2: 既投資、将来の費用・便益、事前条件、条件到達後の選択という要素と関係が固有の製品や手法に依存せず残る。
- R3: 異領域への一般化を採用理由にしておらず、製品開発研究の結果を読者自身の条件設定へ直接一般化しない境界も明示している。
- R4: 自己設定ルールの効果限界、前提の陳腐化、移行費用、客観的ロックイン、閾値到達と自動撤退の違いを適用条件と限界として扱っている。

## 観点別評価
| 観点 | 状態 | 根拠 |
|---|---|---|
| 読者・目的 | 十分 | 過去の投資を惜しんで続行条件を変える継続案件の担当者を具体化し、事前記録を後の費用・便益評価に使う目的が明確である。 |
| 読後の到達点 | 十分 | 原理の説明、条件の具体化、閾値到達後の判断という過不足のない三段階が、未知ケースでの説明と意思決定として確認可能に定義されている。 |
| 内容と順序 | 十分 | 概要、偏りが生じる場面、条件作成、運用の順に前提から実践へ進み、各内容がD1〜D3へ明示的につながっている。 |
| 主張と根拠・境界 | 十分 | 既投資による継続傾向と意思決定支援策の実験結果を一次資料へ追跡でき、確認済みの結果、記事側の運用提案、効果を直接主張できない範囲が区別されている。 |
| 採用・省略 | 十分 | 比較、現実への適用、行動指針はいずれも読者の利用判断に必要な形で採用され、未確認の時代論や過度な一般化・断定は理由を伴って省略されている。 |

## 対応項目
- なし

## 良い点
- 自己設定したルールへの事前コミットでは偏りが大きく減らなかった研究結果を隠さず、条件記録を実証済みの万能策として扱わない設計上の境界が明確である。
- 撤退条件を自動終了命令ではなく再評価の契機として設計し、将来便益・追加費用・移行費用・前提変化を確認して継続、縮小、撤退を選ぶ実用的な判断構造にしている。
