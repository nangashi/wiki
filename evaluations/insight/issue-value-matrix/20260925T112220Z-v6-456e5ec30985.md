# Insight記事評価: issue-value-matrix
- reusability_gate: 合格

## 再利用性ゲート
- R1: 元の資料にない仕事にも使える。未知の作業について、今答える必要性（イシュー度）と答えの明確さ（解の質）を分けて見ることで、次に取る行動（問いの選び直し、分析、探索）を診断できる。四領域の表（29-34行）、確認質問の表（54-58行）、犬の道と探索を見分ける手がかり（76-78行）が、判断の変わる箇所を具体的に示している。
- R2: 固有名を除いても構造が残る。構成は二つの軸、四つの位置とそれぞれ見直す対象、「問いを選ぶ前に作業量で解の質を上げる」という順序、探索との役割の違いである。顧客調査の例（84-90行）は仮想例として切り離されており、同じ領域の別の分析にも同じ要素を当てはめられる。
- R3: 対象外。異領域への一般化を採用理由にしておらず、知的生産の範囲内で再利用するモデルとして書かれている。
- R4: 満たしている。適用の境界の節（94-102行）に次の境界がある。積の式は単位・尺度・閾値を持たない。問いと分析は往復してよい。回答できない問いは分割・探索・保留を検討する。学習や将来の探索の価値は別に扱う。四領域だけで作業の停止や価値を断定しない。右上でも成果の実現は保証されず、左下でも即時停止とは限らない（31・34行）。

## 記事単独読解
- 概念と関係: 安宅和人の二軸モデルを説明している。仕事を「今その問いに答える必要性（イシュー度）」と「その問いにどこまで明確に答えたか（解の質）」に分け、四つの領域で今どこにいて何を見直すかを示す（右上なら判断へ渡す、右下なら分析を進める、左上なら問いを選び直す、左下なら両方を見直すか探索として扱う）。「犬の道」は、問いを選ぶ前に作業量で解の質を上げる進め方のことで、四領域のどれかではなく順序で判定する。探索と犬の道は、作業の目的で見分ける。問いの候補を見つけて更新するための作業なら探索、作り込んでから後で必要な問いにたどり着こうとする作業なら犬の道である。作業量や資料の精巧さは、どちらの軸の高さも示さない。
- 現実の見方: 「資料が詳しくなった」「集計が増えた」を進み具合とみなさなくなり、足りないのが問いの選び直しか、分析か、探索かを見分けるようになる。行動は二つある。作業を足す前に三条件の確認質問を当てる（誰のどの判断を変えるか、なぜ今必要か、どの見立てを確かめるか、期限と資源の中でどう確かめるか）。そのうえで、用途が確かめられていない集計は追加を止めて用途を問い、右下なら候補を区別する情報を取り、探索なら未確定の事項と見直す時点を決めて集める（利用低下の仮想例で三つの場合を示している）。
- 確かさ: 区別できる。原著に由来する部分（二軸、解の質の定義、三条件、犬の道）には出典が付いている。一方、軸の向きと犬の道の図上の経路は二次資料のS8・S9でしか確認されておらず、原著の図は直接見ていないと書かれている。「バリュー＝イシュー度×解の質」の式、確認質問、見分けるための手がかり、職場が作業量で進捗を測るせいで犬の道に陥るという説明は、記事側の提案や解釈だと各所に明記されており、実証済みではないことも書かれている。
- 理解が止まった箇所: 二か所ある。一つ目は、犬の道を図の上では「左側（イシュー度の低い側）を通る経路」と説明する一方で、「イシュー度が低いことは判定の条件ではない」とも書いており、図の経路と順序による定義がどう対応するのか読み取りにくい。「左回り」がどちら向きの回転なのかも、上へ進んでから右へ向かう経路と合わせると分かりにくい。二つ目は、犬の道を判定する条件が「後から必要な問いへ到達しようとしている」という本人の意図にかかっており、挙げられた手がかりが当てはまっても断定できないとされているため、実際に判定を確定する方法が示されていない。

- D3: 実現している。54-58行の表が原著の三条件と記事側の確認質問を列で分け、判断、今の必要性、仮説、回答手段を一続きに点検できる。60行で「なぜ今」を第四の条件としないことを明記している。

## 対応項目
### P1: 図上の経路と、順序による判定の関係を一文で結ぶ
- 種別: 任意改善
- 観点: 論理と構造
- 対象箇所: 「この経路は図の左側、つまりイシュー度の低い側を通って右上へ向かう」／「イシュー度が低いことは判定の条件ではない」
- 問題: 42行では経路を低いイシュー度の側に描き、48行では低いイシュー度を判定条件から外している。44行の「出発しやすく」がつなぎになっているが離れているため、初めて読む人は、図の経路が犬の道の必要条件なのか典型例にすぎないのかで一度つまずく（第一段階の読解で実際に止まった）。
- 改善後に満たす条件: 図の経路は典型的な出発位置と目指す順序を示すもので、判定するのは問いを選ぶ前に作り込むという順序であることが、48行の近くで読み取れる。
- 対応方法: 48行の「イシュー度が低いことは判定の条件ではない」の後に、図の左側を通るのは問いを選ばずに始めた場合の典型的な出発位置を表すためだ、という趣旨を一節加える。

### P2: 例の表一行目の見分ける点を短くする
- 種別: 任意改善
- 観点: 情報設計
- 対象箇所: 「問いを選ぶ前に作り込みを進める順序が確認できるため、犬の道に当たる。この判定にイシュー度の低さは必要ない。一方、必要性が未確認なだけでは…左上にいるとは断定しない」
- 問題: 一つのセルに、判定の根拠、判定に使わない条件、領域を断定しない理由の三つが入っていて、表の中で読み切る負担が大きい。
- 改善後に満たす条件: 表のセルには判定と主な根拠だけが残り、左上と断定しない理由は表の外か次の行動と同じ程度の長さで読める。
- 対応方法: 「左上にいるとは断定しない」の理由部分を表の直後の段落（92行の前）へ移すか、48行ですでに述べている内容と重なる部分を削る。

## 良い点
- 領域と経路を分けて扱っている。「四領域のどれかの名前ではなく、どの順序で進もうとしているかを指す」（40行）と「左上にいるという情報だけでは、そこへ至った順序も今後の進め方も分からない」（48行）により、左上にいることと犬の道であることを取り違えずに済む。
- 出典の範囲を正確に書いている。S1の項目で「原著の図は直接確認していない」「積の表現は…この資料に帰属させていない」と確認できた範囲を示し、解の質の定義から「裏付け」を外して記事側の提案として分けている（19行）。
- 仮想例（88-90行）が、同じ集計作業を犬の道、右下、探索の三つに分け、それぞれの次の行動と、分類してはいけない条件を示している。形式や量だけでは分類できないことが具体的に分かる。
- 探索と見分けるための手がかり（76-78行）が観察可能な応答・報告・計画として書かれ、断定に使わない留保が付いている（80行）。
