# Insight設計評価: issue-value-matrix
- reusability_gate: 合格

## 再利用性ゲート
- R1: 二軸で現在の不足を診断し、第3節の順序で経路を判定し、第5節の役割で探索と見分ける。これにより、元のソースにない作業追加の場面で「問いを選び直す」「分析を進める」「探索へ戻る」を選べる（D2・D4・D5、第6節の三つの場合）。
- R2: 問いの必要性、答えの明確さ、作業量という要素と、作業の順序の関係は、固有の事例を除いても残る。第6節は仮想例と明記されており（l.71）、同一領域の別の調査・分析へ対応づけられる（l.76）。
- R3: 「異領域への普遍性は採用理由にしない」と明記している（l.76）。領域横断を主張しないので対象外である。
- R4: 第7節と境界の各項目（l.45、l.65〜l.71）で、問いと分析の往復、回答不能な問いの分割と保留、学習の副次的価値、四領域の診断で作業の停止を断定しないこと、積を数値採点に使わないことを示している。

## 対応項目
### P1: 積の表現を調べた段落で、頁と版をどの資料が支えるかを分けて示す
- 種別: 任意改善
- 観点: 主張と根拠・境界
- 対象箇所: 「中山政行「図書紹介 イシューからはじめよ」……とflierの同書要約で確認できるのは、原著p.32の二軸マトリクス（横軸イシュー度、縦軸解の質、右上がバリューのある仕事）の説明まで」
- 問題: 「本書P.32」と横軸・縦軸の向きを示すのはJ-STAGEの書評である。flierの公開要約（https://www.flierinc.com/summary/18）では、頁も軸の向きも確認できなかった。flierはURLも記されていない。また、書評は2023年に2010年版を紹介したものなのに、「原著p.32」と版が付いていない。旧版と改訂版の頁を区別するという設計自身の方針（l.53）と比べて曖昧である。積の式が未確認という結論には影響しない。
- 改善後に満たす条件: 頁と軸の向きはJ-STAGEの書評だけに結び付き、「旧版p.32」と版を示している。flierはURLを付けたうえで、確認できた範囲だけに限定するか、確認範囲から外している。
- 対応方法: l.60の一文を「J-STAGE書評では旧版p.32の図として……、flier要約（URL）でも積の式は見当たらない」のように、資料ごとの確認範囲に分けて書き直す。

### P2: 犬の道の経路の解釈に、J-STAGEの書評を補強として加えることを検討する
- 種別: 任意改善
- 観点: 採用・省略
- 対象箇所: 「「左回り」はS8・S9で確認できる表現として用い、図の左側を経由するという説明は軸の向きに基づく記事側の解釈とする」
- 問題: J-STAGEの書評は、犬の道を「第三象限（左下）の領域からスタートし、労働量で解の質を上げ（第二象限（左上））」、そこから「時計回り」で右上へ向かう経路として説明している。これは、左側を経由するという記事側の解釈や、低い領域から出発しやすいという説明（l.25）を補強する独立の二次資料になる。また「左回り」を反時計回りと読むと、この書評の記述と食い違う。そのため、回転方向に言い換えないとするl.25の判断を裏付ける材料にもなる。現状のままでも誤りではない。
- 改善後に満たす条件: 経路の解釈が、S8・S9に加えてJ-STAGEの書評でも追えるかどうかの採否と理由が、設計に記されている。
- 対応方法: J-STAGEの書評を新しいS IDとして記事の外部ソースに加えるか、加えずに設計の注記にとどめるかを決め、l.57〜l.58付近かl.80に一文を足す。

### P3: 積の表現を第1節で導入するか第7節で扱うかの役割を一つにそろえる
- 種別: 任意改善
- 観点: 内容と順序
- 対象箇所: 「表現自体は第7節の境界説明のために残す」
- 問題: 第1節では、概要の段階で積の表現を記事側の概念表現として置くとしている（l.23）。一方、境界ではこの表現を残す理由を第7節の説明のためとしている（l.67）。執筆担当は、概要で積を強調してよいのか、第7節まで控えるのかを迷いうる。
- 改善後に満たす条件: 積の表現を初めて出す節と、残す理由が一致している。
- 対応方法: l.67を「第1節で記事側の表現として導入し、第7節で使える範囲の境界を説明するために残す」のように直す。

## 良い点
- 領域（第2節、現在地の診断）と経路（第3節、順序の判定）を役割で分けている。そのうえで、犬の道の判定に使う基準を第3節の定義一つに集め、ほかの節はそれを参照する形になっている。
- 検証記録の確認済み・未確認・誤りを、そのまま執筆上の境界へ置き換えている。「裏付け」を記事側の提案へ移しているので、原著の定義と実務上の確認が混ざらない。
- 積の表現について、「原著に式がない」と断定せず「未確認」にとどめつつ、出典タグを付けないことで誤帰属を防いでいる。
- 顧客調査の三つの場合それぞれに、現在地、それを見分ける点、次の行動を対応させている。問いが未確定であることや集計の量だけでは分類しないことも、例の中で示している。
