# Insight設計評価: issue-value-matrix
- reusability_gate: 合格

## 再利用性ゲート
- R1: 対象の作業を二軸で点検できる。その結果、未知の作業について「問いを選び直す」「分析を進める」「探索に戻る」のどれを取るかが変わる（設計 D2・D4、第6節の三つの場合と次の行動）。覚えるだけの知識ではなく、判断が変わる。
- R2: 固有名を除いても構造が残る。構造とは、判断の必要性・答えの明確さ・作業量・問いの更新という要素と、「作業量は解の質を保証せず、解の質は必要性を上げない」「必要性の確認を後回しにする順序」という関係である。顧客調査例も同じ領域の別の分析へ移せる構造として扱っている（採用・省略「同一領域の別の調査・分析にも使える構造を残し」）。
- R3: 採用・省略で「異領域への普遍性は採用理由にしない」と明記しているため、R3は必須ではない。
- R4: 次の境界がそろっている。積は点検用の概念表現にとどめる。二軸の統計的独立性は主張しない。領域と経路を区別する。探索と区別する。回答可能性は期限・資源に依存する。学習・探索の副次的価値を残す。四領域で停止や価値の有無を断定しない（主張と根拠・境界の必須境界、第7節）。

## 観点別評価
| 観点 | 状態 | 根拠 |

## 対応項目
### P1: 「バリュー＝イシュー度×解の質」の出典上の位置づけ
- 種別: 調査必須
- 観点: 主張と根拠・境界
- 対象箇所: 「「バリュー＝イシュー度×解の質」は両方の点検を促す概念表現として置く」
- 問題: 資料表でも必須境界でも、積の表現を支える資料と確認範囲が指定されていない。現行記事はこの式にS5・S6を付けているが、今回取得したS5・S6の本文では式の記載を確認できなかった。原著の概念として書くか記事側の表現として書くかを執筆担当が決められず、原著への誤帰属が残るおそれがある。
- 改善後に満たす条件: 積の表現について、原著（または原著を明示して引用した資料）で確認できたか、記事側の要約表現かを設計に記し、記事での帰属の書き方が決まっている。
- 対応方法: 原著の該当箇所を引用した二次資料、または原著の試し読みで式の有無を確かめ、結果を資料表か必須境界に一行で追記する。
- 確認対象: 安宅和人『イシューからはじめよ』が、バリューをイシュー度と解の質の積（掛け算）として表現しているか。
- 必要な理由: 確認できれば原著の表現としてS1に帰属させられる。確認できなければ、二軸マトリクスを要約した記事側の概念表現と明記する必要がある。帰属の文面と出典表記が変わる。
- 調査先: 原著の序章（バリューのマトリクス）の公開抜粋・試し読み（https://www.yondemill.jp/contents/71178?view=1 等）、原著頁を明記して引用した要約・書評、S8・S9本文。
- 結果ごとの対応: 支持時=>S1（確認経路を併記）に帰属させて保持、非支持時=>原著への帰属を外し、記事側の概念表現として記述、結論不能時=>原著に帰属させず記事側の点検用表現として残す（積の概念表現は第7節の境界説明に不可欠なため、表現自体は省略しない）

### P2: 第3節の順序を未知ケースで確かめる観察可能な手がかり
- 種別: 任意改善
- 観点: 内容と順序
- 対象箇所: 「作り込むことで後から重要な判断に答える問い・位置へ到達しようと考えているため、第3節の順序が確認できる」
- 問題: 第3節の順序は作業者の意図（後から到達しようとする）で定義されている。第5節と必須境界は「〜だけで犬の道としない」という否定条件を重ねている。仮想例では意図が設定済みなので判定できるが、他人や過去の作業を点検するとき、読者が何を観察して順序を確かめるのかが「作業量や網羅性が進捗の代わりになる」の一句に頼っている。
- 改善後に満たす条件: 第3節または第5節に、順序を確かめる肯定的な手がかりが短く示されている。例として、追加作業の用途（誰のどの判断）を問われても答えられない、作業量や網羅性を進捗として報告している、結果を問いの候補の更新に使う予定がない、が挙げられる。
- 対応方法: 第5節の「犬の道では」の説明に、上記の手がかりを記事側の実務提案として一〜二文加えるよう設計に追記する。

## 良い点
- 現行記事の誤りを正している。現行記事は右下を「犬の道」、左上を「粗削りだが有望」としていた。設計は軸の向き（横軸はイシュー度、縦軸は解の質）をS8・S9で確かめ、四領域を正しく配置し直した。そのうえで、犬の道を領域名ではなく経路として定義している。
- 「左回り」の扱いが慎重である。S8・S9の表現として保持し、「図の左側を経由する」という意味づけは記事側の解釈と明記している。さらに「反時計回り」への言い換えを禁じている。二次資料の間でも回転方向の表現が揺れているため、読者の混乱を防ぐ判断として保持すべきである。
- 解の質の原著定義に「裏付け」を加えない境界を、許可された確認記録（evaluations/insight/issue-value-matrix/external/f395296ccf7e-external-840694224f6b.md）に沿って置いている。根拠確認は記事側の提案として切り分けている。
- 第6節の三つの場合（用途未確認の集計追加、必要な問いへの回答不足、原因候補を探す初期調査）で、同じ「集計・調査」でも現在地と次の行動が分かれることを示している。「問いが未確定なこと」や「調査量の多さ」だけで分類しない判定も含まれる。
- 統合元の過剰な断定を引き継がない。対象は「どちらの結果でも行動が変わらなければ不要」、本質的問題2〜3%、作業100分の1、出典未確認の警句である。一方、統合元が独自に持っていた「作業量が目に見える進捗になる」という説明は、記事側の説明として保持している。
