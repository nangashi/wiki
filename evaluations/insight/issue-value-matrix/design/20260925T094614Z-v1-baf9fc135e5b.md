# Insight設計評価: issue-value-matrix
- reusability_gate: 合格

## 再利用性ゲート
- R1: 設計は二軸を使う判断を定めている。一つは、作業の不足が「問いの必要性」と「答えの明確さ」のどちらにあるかの診断である（D2）。もう一つは、情報収集が探索なのか、問いの確認を後回しにした作り込みなのかの見分けである（D4）。どちらも資料にないケースに使える。第6節は、その判断を仮想例の三つの場合に当てはめる形で書かれている。
- R2: 固有名を除いても構造が残る。構造は「判断の必要性」と「その判断への答えの明確さ」という二つの要素、両者の区別、そしてどちらを先に上げるかという順序である。第7節の境界は「同一領域の別の調査・分析にも使える構造」を想定している。
- R3: 採用・省略の節は「異領域への普遍性は採用理由にしない」と明記している。異領域への一般化を主張しないので、R3は必須条件にならない。
- R4: 第7節と必須境界に適用条件が明記されている。対象は次の五つである: 積を概念表現に限ること、問いと分析の往復、回答不能な問いの分割・探索・保留、学習・探索の副次的価値、右上が成果を保証せず左下が即時停止を意味しないこと。

## 観点別評価
| 観点 | 状態 | 根拠 |
|---|---|---|
| 読者・目的 | 十分 | 読者は「精巧な分析や資料を作っても判断が進まず、さらに調査や作り込みを足そうとしている」人と具体的である。判断の選択肢も「問いを選び直すか、分析を磨くか、探索に戻るか」の三つとして定まっている。統合の前提と、slug・タイトルを維持することも明示されている。統括の統合判断は妥当である。犬の道は、統合先のモデルと同じ二軸の上での経路なので、独立記事では原理が重複していた。現行の二記事では犬の道の位置づけも食い違っている（現行記事は右下の領域名、統合元は経路）。 |
| 読後の到達点 | 十分 | D1〜D5は、定義、診断、三条件、経路と探索の区別、境界に分かれており、各節の対応先も決まっている。統合元の旧D1〜D3（経路、探索との区別、作業前の点検）はD3・D4に吸収されており、落ちた到達点はない。 |

| 採用・省略 | 十分 | 比較・現実への適用・行動指針の三つとも、採用理由と役割（診断・経路・見分け方）が書かれている。統合元の独自内容のうち、経路比較、探索との区別、作業前の点検、「進捗の代わりになる作業量」は残っている。一方、現行・統合元にあった根拠のない表現は省略されている（本質的問題の割合、100分の1、ドラッカーの警句、「右下: 犬の道」「即刻停止」「成果に直結」）。関連リンクの採否にも理由がある。 |

## 対応項目
### P1: 犬の道の判定基準を第3節・第5節・第6節で一つにそろえる
- 種別: 修正必須
- 観点: 内容と順序
- 対象箇所: 「必要性が未確認なだけではイシュー度が低いと断定せず、…必要性の低い問いへの回答を先に磨き、後から必要性を高めようとしているなら犬の道に当たる。」
- 問題: 第3節とD4は犬の道を「イシュー度の低いまま」解の質を先に上げる経路と定義している。第5節は「問いの必要性の確認を後回しにして答えの作り込みを進める」かどうかという作業の役割で見分ける。第6節の集計追加の例は、第5節の基準では該当すると書きながら、第3節の条件（イシュー度が低いこと）が分からないとして判定を保留している。そのため読者は、自分の作業が犬の道かどうかを何で判断するのかが分からず、D4の「探索と見分けられる」に到達できない。なお資料側（S6「手当たり次第に始める」、S8「思いつくまま、とにかく労働量によって上に行き」）は、「問いを選ばずに作業から始める順序」を中心に据えている。
- 改善後に満たす条件: 犬の道の判定条件が、D4、第3節、第5節、第6節で同じになっている。定義の軸は「イシュー度の確認・選択を後回しにして作業量で解の質を先に上げる順序」か「イシュー度が低いこと」のどちらかに統一されており、もう一方との関係（例: 低イシュー度は典型的な出発点、あるいは結果として起きやすい状態）も明記されている。第6節の集計追加の例は、その条件で分類が確定するか、分類に必要な追加情報が一つに特定されている。
- 対応方法: D4と第3節の定義を、S6・S8の表現に合わせて「問いの必要性を確かめる前に作業量で解の質を上げ、後から必要性を得ようとする順序」を中心に書き直す。「イシュー度の低い領域から出発しやすい」ことは説明として添える。そのうえで第6節の該当行から条件付きの保留を外し、第5節の基準をそのまま当てはめた分類と次の行動を示す。

### P2: 統合後も「犬の道」で記事を見つけられるようにする
- 種別: 任意改善
- 観点: 採用・省略
- 対象箇所: 「記事タイトル『イシュー度×解の質マトリクス』とslug `issue-value-matrix`を維持する。」
- 問題: 独立記事の削除後、「犬の道」で探す読者がこの記事にたどり着く手がかりが、設計上は本文の第3節にしかない。
- 改善後に満たす条件: 概要か冒頭の定義で、犬の道がこの二軸上の失敗経路として扱われていることが早い段階で示されている。
- 対応方法: 第1節の伝える内容に、犬の道を本記事で扱うことを一文で示す指示を加える。

### P3: 「左回り」の解釈が推論であることを示す
- 種別: 任意改善
- 観点: 主張と根拠・境界
- 対象箇所: 「『左回り』は原著由来の呼び名で図の左側を経由して上へ進む経路を指すため」
- 問題: S8・S9で確認できるのは「左回りで右上」という表現だけである。「図の左側を経由する経路を指す」という意味づけは、その表現と軸の向きから導いた推論であり、原著の説明として確認されたものではない。
- 改善後に満たす条件: 本文で「左回り」の意味を説明する箇所が、二次引用で確認できる表現と記事側の解釈を区別している。
- 対応方法: 必須境界の「領域と経路を区別する」の項に、左回りの意味づけは軸の向きからの解釈であると一句加える。

## 良い点
- 現行記事は「右下: 犬の道」という誤った領域名を付け、象限の割り当ても取り違えていた。設計はこれを、二次資料2件で確認した軸の向きに基づいて正し、領域（第2節の診断）と経路（第3節の順序）を別の節に分けている。
- 解の質の定義を確認記録どおり「明確さ」にとどめ、「裏付け」「検証」は記事側の実務提案として分けている。
- 統合元にあった「探索との区別」を、作業の役割（未確定事項と見直し時点を置いているか）で見分ける基準へと具体化している。例より前に説明するよう順序も決めているので、調査の量だけで犬の道と判定する誤読を防げる。
- 仮想例の三つの場合を、それぞれ第2節・第3節・第5節と次の行動に対応づけている。二択が網羅的でないことや、分類を固定しないという境界も書かれている。
