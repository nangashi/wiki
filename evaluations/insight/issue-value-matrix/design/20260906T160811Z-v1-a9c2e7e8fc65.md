# Insight設計評価: issue-value-matrix
- reusability_gate: 合格

## 再利用性ゲート
- R1: 二軸の組合せから問い・根拠・判断の優先順位を導ける。
- R2: 必要性と解答度の関係は個別の分析事例を除いても残る。
- R3: 異領域一般化を採用理由にしておらず適用対象外である。
- R4: 判断主体・期限による変化と探索目的への限界を示している。

## 観点別評価
| 観点 | 状態 | 根拠 |
|---|---|---|
| 読者・目的 | 十分 | 読者の問題状況と、改善対象を選ぶ使い道が具体的である。 |
| 読後の到達点 | 十分 | 定義の区別、判断、誤用回避を確認可能な形で示している。 |
| 内容と順序 | 十分 | 定義から事例、組合せ別行動、境界へ順に理解を進められる。 |
| 主張と根拠・境界 | 要対応 | 解の質の中核的定義だけ一次資料による確認が未解消である。 |
| 採用・省略 | 十分 | 比較・適用・行動を採り、数理法則化などの誤用を省いている。 |

## 対応項目
### P1: 解の質の定義を一次資料で確定する
- 種別: 調査必須
- 観点: 主張と根拠・境界
- 対象箇所: 「解の質を問いにどこまで答えられているか」
- 問題: D1の中核定義だが、設計自身が一次の公開抜粋では定義文を確認できていないとしており、著者の定義と記事側の具体化の境界を確定できない。
- 改善後に満たす条件: 解の質の定義を一次資料へ追跡できるか、記事側の操作的定義として明示する。
- 対応方法: 書籍該当頁を確認し、確認結果に応じてS5の支持範囲とD1の表現を最小限修正する。
- 確認対象: 著者が解の質を「問いにどこまで明確に答えを出せているか」と定義しているか。
- 必要な理由: 結果によりD1を原著の定義として保持するか、記事側の提案へ変更するかが決まる。
- 調査先: 『イシューからはじめよ』旧版p26前後または出版社・著者による同箇所の公開抜粋。
- 結果ごとの対応: 支持時=>定義と出典頁を保持、非支持時=>記事側の定義へ修正、結論不能時=>原著への帰属を外して記事側の点検定義とする。

## 良い点
- 二軸の誤用を防ぐ境界を到達点と構成の両方へ組み込んでいる。
