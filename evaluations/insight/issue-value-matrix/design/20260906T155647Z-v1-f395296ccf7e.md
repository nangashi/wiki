# Insight設計評価: issue-value-matrix
- reusability_gate: 合格

## 再利用性ゲート
- R1: 二軸の状態から問いの再設定か根拠追加かを判断できる。
- R2: 必要性と解の質の関係は固有事例を除いても成立する。
- R3: 異領域一般化を採用理由にせず主な射程を限定している。
- R4: 期限・利用者・目的による変化と探索への不適用を示す。

## 観点別評価
| 観点 | 状態 | 根拠 |
|---|---|---|
| 読者・目的 | 十分 | 判断用途が曖昧な分析担当者と使い道が具体的である。 |
| 読後の到達点 | 十分 | 区別、行動選択、誤用回避まで過不足なく定めている。 |
| 内容と順序 | 十分 | 定義、同一事例、行動、境界の順で到達点へつながる。 |
| 主張と根拠・境界 | 要対応 | 二軸自体は確認できるが解の質の定義は出典上未確認である。 |
| 採用・省略 | 十分 | 比較・適用・行動を採り、数理法則化などを妥当に省く。 |

## 対応項目
### P1: 解の質の定義を一次資料へ追えるようにする
- 種別: 調査必須
- 観点: 主張と根拠・境界
- 対象箇所: 「解の質を問いへの答えの明確さ・裏付け」
- 問題: 掲載URLは二軸の区別を支持するが、この定義までは示さず、著者由来の定義か記事側の操作化か判断できない。
- 改善後に満たす条件: 解の質の構成要素を一次資料で確認し、出典箇所を示すか記事側の提案として明記する。
- 対応方法: 書籍の該当箇所で定義を確認し、支持範囲に合わせてD1と根拠記述をそろえる。
- 確認対象: 解の質が答えの明確さと裏付けとして定義されるか。
- 必要な理由: 結果により中心概念の定義と二軸比較の説明を保持または修正する必要がある。
- 調査先: 安宅和人『イシューからはじめよ』の解の質を定義する箇所。
- 結果ごとの対応: 支持時=>該当頁を明記して保持、非支持時=>原著に沿う定義へ修正、結論不能時=>記事側の操作化と明記する。
