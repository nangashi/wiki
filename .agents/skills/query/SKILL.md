# $query スキル

wikiを検索して質問に答える。wikiに情報が不足している場合はWebで補完し、新たな知見があればwikiへの追加を提案する。

検索範囲が広い場合は`finder`（Luna / medium）に関連箇所と根拠の抽出を委譲し、Astraが統合して回答する。単純な照会は直接処理し、子を必須にしない。複雑で論争のある統合、または根拠の競合が回答を左右する場合だけ、**`evaluator`（Sol / low）** に草稿と根拠の独立検証を依頼する。Astraは最終的な採否と統合を決める。

## 事前準備

`wiki/collections.md` を読み、コレクション構成を確認する。

---

## 処理フロー

### ステップ1: wikiを検索する

1. `wiki/insight/index.md` と `wiki/it/index.md` を読み、全コレクションのページ一覧を把握する
2. 質問に関連しそうなページを特定する（スラグ名・index のサマリからあたりをつける）
3. 関連ページを読む（コレクションをまたいで読む）
4. 関連ページからさらにリンクされているページも必要に応じて読む

被リンクから探す場合は `python3 .agents/skills/lint/wiki_structure.py backlinks <collection>:<slug>` で参照元を取得する。

### ステップ2: wiki情報で回答できるか判断する

**wikiで十分な場合**（以下をすべて満たす）:
- 質問の核心部分をwikiが直接カバーしている
- 情報が具体的で、あいまいな記述でない
- 追加の文脈なしに理解できる

→ **ステップ3（Wiki回答）** へ

**Webを使う場合**（いずれかに該当）:
- wikiに該当概念のページがない
- wikiにページはあるが情報が不足・断片的
- 最新情報が必要な質問

→ **ステップ4（Web補完）** へ

### ステップ3: wikiから回答する

wikiの情報をもとに回答を構成する。引用元のページを `[[スラグ]]` で明示する（クロスコレクション参照の場合は `[[insight:スラグ]]` / `[[it:スラグ]]` 形式）。

その後、必要なら独立検証を行い、ステップ5へ。

### ステップ4: Webで情報を補完する

1. 質問に関連するキーワードでWeb検索を実行する（1〜3回）
2. 得られた情報を統合して回答する
3. 参照したURLをリストアップする

必要時の`evaluator`には、質問、草稿、参照したwiki本文とWeb URLだけを渡す。wiki根拠のない主張を除外またはwiki外の知見と明示し、因果・階層を確認し、見落とした上流の問いと「なぜ」の不足を指摘させる。以前の判定や結論は渡さない。記事評価とは別の回答検証として、観点ごとに「問題箇所／根拠／修正案」を返すよう指定する。

### ステップ5: wikiへの追加を判断する

**以下のいずれかに該当する場合のみ** wiki追加を提案する:

| 追加が必要な状況 | 説明 |
|----------------|------|
| **新たな知見** | wikiに存在しない情報・概念・事実が得られた |
| **ページ間の新接続** | 既存の2つ以上のwikiページが実は関連していることが判明した（リンク未設定） |
| **既存ページの補強** | 既存ページの説明に重要な補足情報が加わる |

追加を提案する場合、`wiki/collections.md` の判定目安に照らしてどのコレクションに追加するかも提示する。

**追加不要な場合** (提案しない):
- 単純にwikiの内容を言い換えただけ
- 質問への直接回答だが、wiki的な知識としての独立性がない（例: 「〇〇の設定コマンドは？」）
- 既にwikiに記録済みの内容

### ステップ6: `$ingest` へ引き渡す（提案が承認された場合）

`$query` 自身はwiki、index、関連ページを変更しない。ユーザーが追加に同意したら、参照URL、回答で得た知見、追加先候補、新規／追記案を `$ingest` への入力として引き渡す。

insightでは再利用性ゲート、重複確認、調査、草稿、独立評価、改善、新しい独立再評価を省略しない。itでも `wiki/it/schema.md` に従う。query中の回答や`evaluator`結果を、評価済みの記事として直接書き込まない。

## 出力形式

```
## 回答

<構造化・補強済みの回答本文>

参照: [[スラグ1]], [[insight:スラグ2]]（wikiから回答した場合）
参照: https://url （Webから補完した場合）

---

## 独立検証メモ（実行した場合のみ）

- 追加した視点: ...
- 除外・修正した主張: ...
- 構造の変更点: ...

---

## wiki追加の提案（該当する場合のみ）

以下の知見をwikiに追加することを提案します:

### 提案1: [新規ページ or 追記] — タイトル
**コレクション**: insight / it
**理由**: 新たな知見 / ページ間の新接続 / 既存ページの補強
**内容**: <追加する情報の要約>
**対象**: [[スラグ]]（追記の場合）

---

追加しますか？（「はい」で `$ingest` に引き渡し、「いいえ」でスキップ）
```

## 注意事項

- 回答の質を落としてでもwikiに情報を詰め込もうとしない
- Webの最新情報とwikiの情報が矛盾する場合は、その矛盾をユーザーに伝える（`$lint` の実行も提案する）
- `evaluator`の検証で草稿を大幅に変更した場合、その理由をユーザーに簡潔に説明する
